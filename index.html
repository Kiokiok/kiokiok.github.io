Cliffdivers ( 2023 )

PC GAME
Role Studio Team Size Status Duration
Lead Programmer Unamed 4 people Unreleased 12 months

Project description

A procedural multiplayer survival adventure game.

My latest and biggest project to date. I worked full time on this project for all of 2023, with the end goal of co-founding a studio. I left the team at the beginning of 2024 for personal reasons, but the project was a lot of fun to work on and I learned a lot while working on it. I was the sole programmer on the team, and handled pretty much every technical aspect of it. The game features an open, vertical, procedural world explorable in multiplayer. The players have many tools available to help them traverse the atypical world. The goal of the game is to go down further and further down in an unexplored abyss and uncover its mysteries and history. At the time of me leaving, most of the underlying engine was functional (world streaming, networking) and gameplay mechanics where starting to get implemented. The game uses a data-driven approach to a lot of things : Entity declaration, Items declaration, Character controller configuration, among other things. This was done to help development time and later on help bring modding support to the game.

Technical information :

  • Engine : Godot
  • Responsible for the entirety of the programming
  • Languages used : C#, LUA, C++, GDScript

Notes :

  • Integrated Flecs on top of Godot engine ( ECS )
  • Built a network entity replication system on top of Enet ( creation, deletion, state change)
  • Built a custom renderer system to render entities efficiently
  • Used a data-driven approach to declare entities, items, crafting recipes, using the LUA scripting langage
  • Built a basic network interest manager and world streaming system
  • Built a custom entity spawning system on top of VoxelTools
  • Built an extensive state machine system for the character controller
  • Implemented the character controller and various gameplay tools
  • UI programming
